ModelRepoFinder v1.6.1

Find open-source models and GitHub projects that fit your house, then download only the ones you approve. Nothing leaves this computer except requests to Hugging Face or GitHub.

This is a preview mode. Nothing downloads until you click Approve & download.

You can paste a path now, or later point this at a shared folder or NAS. Click Save folder after you change it. Category choices are remembered per computer, so each machine can search a different set.

Scheduled auto-scan

While this app is open, it can look for new models on a schedule you set, download ones that match your conditions (up to the limits you choose), and tidy out-of-date ones it downloaded itself. Turning this on is your standing approval for those matching models — they will be downloaded without a separate Approve click. Use Dry run first if you want to see what would happen. Cleanup is skipped if a search or download fails, and the default is to move old models to the retired folder, not to delete them. Manual downloads and models this app only found on the computer are left alone unless you opt one in.

What to look for

Tick the categories to search, and optionally include Top picks (popular models that should fit, using Hugging Face community numbers). Popularity is a signal, not a quality guarantee.

Limits

Cleanup of out-of-date models

This only applies to models the schedule itself downloaded, or ones you opted in below. It will not touch models this app only found on the computer. At least one model is always kept in each category, and cleanup waits until downloads in the same run have finished and been checked. The default is to retire (move) a model, which can be undone by moving it back.

Permanent deletion cannot be undone.

This still only applies to models the schedule downloaded or that you opted in. Type DELETE in the box below, tick the confirmation, and click Save settings. You will also be asked to confirm in a dialog.

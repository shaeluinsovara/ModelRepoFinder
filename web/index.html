ModelRepoFinder v1.3

Find open-source models and GitHub projects that fit your house, then download only the ones you approve. Nothing leaves this computer except requests to Hugging Face or GitHub.

This is a preview mode. Nothing downloads until you click Approve & download.

You can paste a path now, or later point this at a shared folder or NAS. Click Save folder after you change it. Category choices are remembered per computer, so each machine can search a different set.
